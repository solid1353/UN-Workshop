UN Workshop

  ws <game|iso-path> [game|iso-path] [options]  Launch or replay one or two games
  ws resolve [source] [property]                Resolve sources and their properties
  ws input [profile]                            Regenerate profiles; optionally assign one
  ws pcsx2                                      Launch development PCSX2
  ws help                                       Show this help

  Launch modes:
    -p <name>        Replay an input recording without captures
      -agent-replay  Agent-controlled playback; paused and surfaceless
        -logfile <path>  Required PCSX2 log destination
    -r <name>        Create an input recording
    -s <name>        Replay and capture screenshots and savestates
      -o <path>      Snapshot output directory

  Launch options:
    -mc <card>       Card path or template number/name; none disconnects all slots
    -vmc [card]      Keep changes in RAM
    -dmc [card]      Discard writes
    -pnach <file>    Additional PNACH; repeatable
    -t               Turbo
    -u               Unlimited
